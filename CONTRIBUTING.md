# Contributing

Thanks for your interest in Vantage.

## Code contributions

Vantage doesn't accept code contributions yet: pull requests from outside the project will be
closed without review for now. This may change once the project settles.

## What helps most

- **Bug reports.** Open an issue with the *Bug report* form.
- **Hardware findings.** If an integration shows wrong, missing or odd data for your device,
  or works well on a model that isn't listed, open an issue with the *Integration finding*
  form. Device model, firmware version and Vantage version make a report useful.
- **Questions and ideas** go to [Discussions](https://github.com/levi-xy/vantage/discussions).

Whatever you post, leave out IP addresses, hostnames, domains, usernames, tokens, passwords
and community strings. Use placeholders such as `192.0.2.10`, `switch.example` or
`example-token`.

## Security

Report vulnerabilities privately, as described in
[docs/SECURITY.md](docs/SECURITY.md#reporting-a-vulnerability), never in a public issue.
