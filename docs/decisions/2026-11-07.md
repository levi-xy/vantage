# 2026-11-07

- **Network maps** (Contract 2, `network_maps`, "Network maps"; Contract 3, `/maps`; frontend rules): user-drawn maps replace the `links` table and the `/links` API. The migration turned the old `links` rows into a first map. Maps are a JSON document (at most 500 elements, 256 KB), saved with a revision check (409 on conflict); create, rename/move and delete audited, drawing saves not. On a phone the map page lists devices and problems instead of the drawing. Milestone M9.
- **Timezone** (Contract 2, "Time" and the `settings` row `timezone`; Contract 3, `/settings/time`; frontend rules): one admin-chosen IANA zone for web pages, Telegram messages, log lines and CLI output; stored data stays UTC; the clock comes from the host. Admin pages move under Settings. Milestone M10.
