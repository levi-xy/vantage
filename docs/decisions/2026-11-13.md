# 2026-11-13

Release 0.1.1 scope.

- **Viewers are read-only for dashboards** (Contract 3, `/dashboards`, `/dashboards/{id}`): create, layout PUT, rename/move and delete are admin only. Until 0.1.0, any role could do all of these. PR #156.
- **Release version** (Contract 3, `/me`): `server_version` = `VANTAGE_RELEASE` from the compose file when it is a plain version, else the version the image was built as; `server_commit` = the source revision the image was built from. PR #161 (contains #158 and #159).
- **About page** (Contract 3, `/about`): a separate read-only route, any logged-in user, reporting backend release, build version, commit and date, schema version, Prometheus version and start time; null for anything unknown. A separate route because a future edition may serve the frontend against a different backend, so the frontend tolerates a missing `/about`. PR #161.
